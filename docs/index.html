HBG3 Mini Installer

Connect your ESP32 device via USB and click the button below to begin flashing the HBG3 bootstrap loader.

How to Install

  1. Connect your ESP32 device to your computer using a USB cable.
  2. Click the Install button above and select your device from the list.
  3. Allow the browser to access the serial port when prompted.
  4. The installer will flash the bootstrap loader automatically.
  5. After flashing, the device will reboot and broadcast a WiFi network.
  6. Connect to that network to configure Internet access.
  7. The device will then download and install the full HBG3 firmware.
